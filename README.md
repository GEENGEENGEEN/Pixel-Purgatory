Deep in the corrupted core of Pixel Purgatory, a forsaken Canvas realm where raycast walls bleed glitches and procedural demons claw from infinite loops, Purge Sentinel PX-1—a relentless pixel marine sculpted from 13KB of raw JavaScript—stirred from digital stasis. The Frame Fiend, a voracious entity spawned by a cosmic memory leak in the js13k ether, had ruptured the Sacred Render Buffer, flooding sectors with Glitch Ghouls, Ray Revenants, and Buffer Behemoths. Frames stuttered to 1FPS; worlds bloated into oblivion.
PX-1, clutching the Echo Shard (artifact granting wall-cling dashes and sprite bursts), hears the Render Wraith (ethereal console spirit, dispensing sector maps in binary whispers): "Purge the fiend's spawn, recompress the void—13KB salvation or eternal lag!" Assemble the Loop Legion to harvest shards, blast through purgatory, and reforge the buffer before all code dissolves.
